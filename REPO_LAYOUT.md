# What's in this repo

- `anthroforge-app/` — the application: character core (9 modules),
  Telegram Mini App + bot, MCP server, tests, slider/preset library.
  Pass 1 + Pass 2 fixes (Nov 14, 2026) are in.
- `anthroforge-v2/` — the v2 work tree: the 3D Pro web app
  (`anthroforge_3d_pro_v2.html`), prototype code, head/body studies,
  and the built character work (GLBs, renders) loaded with release
  v1.0.0 on Nov 16, 2026.

Third-party originals pulled for study are not redistributed here —
see `NOT_INCLUDED.md` for the exclusion list. The full reference
libraries live in the local parts library and the Google Drive
models library.
